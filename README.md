# EasyPDF v2.0

> **Stop reading PDFs. Start extracting raw intelligence.**

EasyPDF is an AI-powered PDF summarization application. Upload any text-based PDF and receive a structured, in-depth summary report generated by Google Gemini AI — in seconds.

---

## Tech Stack

| Layer | Technology |
| :--- | :--- |
| Framework | Next.js 16 (App Router, Server Actions) |
| Auth | Clerk |
| File Storage | UploadThing (direct S3 uploads) |
| PDF Parsing | LangChain (`@langchain/community` PDFLoader) |
| Primary LLM | Google Gemini 2.5 Flash |
| Fallback LLM | OpenAI GPT-4o |
| Database | Neon Serverless PostgreSQL |
| Styling | Tailwind CSS v4 + Radix UI |

---

## How It Works

1. **Upload** — User uploads a PDF (up to 16MB) via a drag-and-drop interface. The file is streamed directly to UploadThing cloud storage.
2. **Parse** — The server fetches the PDF, extracts text page-by-page using LangChain's `PDFLoader`, and splits it into 8,000-character chunks.
3. **Summarize** — Each chunk is individually summarized (for multi-chunk documents), then a final comprehensive report is generated using the structured prompt.
4. **LLM Fallback** — Gemini 2.5 Flash is the primary model. If Gemini fails after 3 retries (1s and 2s delays), the pipeline **automatically falls back to OpenAI GPT-4o** to ensure the user always gets a result.
5. **Store & View** — The final Markdown summary is saved to Neon PostgreSQL and displayed in a formatted report view.

## Features

- ✅ AI-powered PDF summarization (Gemini 2.5 Flash)
- ✅ Automatic LLM fallback to GPT-4o on Gemini failure

## Local Setup

### 1. Clone and install
```bash
git clone <your-repo-url>
cd EasyPDF
npm install
```

### 2. Configure environment variables
Create a `.env.local` file in the project root:
```env
# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_...
CLERK_SECRET_KEY=sk_...

# Neon PostgreSQL
DATABASE_URL=postgresql://...

# UploadThing
UPLOADTHING_TOKEN=...

# Google Gemini
GEMINI_API_KEY=...

# OpenAI (fallback)
OPENAI_API_KEY=sk-...
```

### 3. Run the database schema
Apply `schema.sql` to your Neon database using the Neon console or `psql`.

### 4. Start the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
